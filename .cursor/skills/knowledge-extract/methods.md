# 方法论详细说明

## 一、结构化表达模型

### 金字塔原理（Pyramid Principle）

**适用**：汇报、方案、技术文章、年终总结

**操作步骤**：
1. 写出「核心结论」（一句话，放在最前）
2. 列 3-7 个「支撑论点」（每个能独立支撑结论）
3. 每个论点下附「数据/案例/事实」佐证
4. 用 MECE 检验：论点间无重叠，合起来完全覆盖结论

**质检**：把正文遮住，只看结论 → 结论是否独立成立？

---

### KISS 模型（Keep It Simple and Stupid）

**适用**：电梯演讲、高层汇报、周报摘要

**操作步骤**：
1. 写初稿
2. 删除所有形容词和副词，保留核心动词+名词
3. 每句话不超过 20 字
4. 整体不超过 200 字

**质检**：读给不了解背景的人，30秒内能否理解核心？

---

### ORID 焦点讨论法

**适用**：会议纪要、项目复盘、个人成长总结

**四层结构**：
- **O（Objective，客观）**：发生了什么？有哪些客观事实、数据、现象？
- **R（Reflective，感受）**：参与者的反应/情绪？哪些让人兴奋/担忧？
- **I（Interpretive，诠释）**：这意味着什么？有什么规律或洞察？
- **D（Decisional，决定）**：接下来做什么？具体行动是什么？

**质检**：每层是否都有内容？是否从事实自然过渡到行动？

---

## 二、复盘与迭代模型

### GRAI 复盘模型

**适用**：项目复盘、阶段性总结、重要事件回顾

**四步操作**：
1. **G（Goal，目标）**：当初设定的目标是什么？量化指标是什么？
2. **R（Result，结果）**：实际达成了什么？数据是多少？
3. **A（Analysis，分析）**：目标与结果的差距从哪里来？主观/客观原因各是什么？
4. **I（Insight，洞察）**：提炼出「以后遇到类似情况的通用做法」（而非只是这次的教训）

**关键**：Insight 必须是可迁移的规律，而非"下次要注意"之类的泛泛之词。

**质检**：Insight 能否直接写进 SOP？

---

### PDCA 戴明环

**适用**：长线项目持续改进、流程优化跟进

**循环操作**：
- **P（Plan）**：目标 + 方案 + 指标
- **D（Do）**：执行记录（关键节点，非流水账）
- **C（Check）**：实际结果 vs 计划，差距分析
- **A（Act）**：成功经验 → 标准化；失败教训 → 纳入下一轮 P

**质检**：A 阶段是否产出了可落地的 SOP 或规范变更？

---

### KPT 模型

**适用**：周会、日报、敏捷迭代回顾（轻量级）

**三栏结构**：
- **K（Keep，保持）**：哪些做法有效，下周继续？
- **P（Problem，问题）**：遇到了哪些阻碍？（只描述现象，不归因）
- **T（Try，尝试）**：针对每个 Problem，下周具体尝试什么解法？

**质检**：每个 Problem 是否对应一个 Try？Try 是否具体可执行？

---

### ECRS 分析法

**适用**：流程优化、效率提升、工作方式改进

**四步检查**：
1. **E（Eliminate，取消）**：哪些步骤完全没必要，直接删除？
2. **C（Combine，合并）**：哪些步骤可以合并为一步？
3. **R（Rearrange，重排）**：改变顺序是否能提效？
4. **S（Simplify，简化）**：每个步骤内部可以怎么简化？

**操作**：先列出所有流程步骤，逐一用 ECRS 四个视角审查。

**质检**：优化后流程步骤数是否减少？单步骤时长是否降低？

---

## 三、深度认知方法

### 四步思维法：拆分→归纳→联系→提炼

**适用**：碎片化信息整合、跨领域知识提炼

**四步操作**：
1. **拆分**：把复杂内容切成最小知识单元（每单元只表达一个概念）
2. **归纳**：找各单元间的共性，分组贴标签
3. **联系**：与已有知识/其他领域建立连接（"这和XX很像"）
4. **提炼**：抽象成一句话结论："核心是……（结论），因为……（证据）"

**质检**：最终结论能否用一句话说清楚？能否向外行解释？

---

### 费曼技巧 + 输出倒逼输入

**适用**：学习笔记、读书总结、技术消化

**操作步骤**：
1. 读完材料后，合上原文
2. 用大白话写给"完全不了解这个领域的人"看
3. 遇到卡壳或只能堆砌术语 → 说明没真懂，回去补课
4. 重复直到能通俗表达为止
5. 最后浓缩成一个「核心概念图」或「一句话定义」

**质检**：一个 10 岁的孩子能否看懂？

---

### MECE 原则（分类质检工具）

**用途**：检验总结框架是否严谨（不单独使用，配合其他方法作为检验工具）

**两个检查**：
- **互相独立（ME）**：各分类是否有重叠？重叠的合并
- **完全穷尽（CE）**：是否遗漏了重要类别？补充遗漏项

**常用分组维度**：时间维度、空间/领域维度、原因维度（人/机/料/法/环）、重要性维度（高/中/低）

## 方法选择速查

```
用户问题 → 推荐方法

"帮我总结这个会议" → ORID
"项目做完了，帮我复盘" → GRAI
"这篇技术文章太长，帮我提炼" → 四步思维法 + 金字塔原理
"现在流程太繁琐，帮我整理" → ECRS
"帮我把这本书/文章的核心内容说清楚" → 费曼技巧
"帮我写周报/汇报" → KPT + KISS
"帮我整理一个决策文档" → 金字塔原理 + MECE
"这些信息很杂，帮我整理" → 四步思维法（拆→归→联→提）
```
