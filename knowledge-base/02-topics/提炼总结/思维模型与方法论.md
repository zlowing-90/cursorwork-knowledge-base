> **核心结论**：提炼总结的本质是"结构化降噪"——从碎片信息中抽取可迁移的规律，输出一句话结论 + 有据可查的支撑体系。

## 三大维度

### 一、结构化表达（让总结清晰有力）

| 方法 | 核心 | 适用场景 |
|------|------|----------|
| **金字塔原理** | 结论先行，以上统下，归类分组 | 汇报、方案、技术文章 |
| **KISS** | Keep It Simple，最简语言最短篇幅 | 电梯演讲、高层汇报 |
| **ORID** | 事实→感受→诠释→行动 | 会议纪要、项目复盘、个人成长 |

### 二、复盘与迭代（让经验可复制）

| 方法 | 核心 | 适用场景 |
|------|------|----------|
| **GRAI** | 目标→结果→分析→洞察 | 项目复盘、阶段总结 |
| **PDCA** | 计划→执行→检查→标准化 | 长线项目持续改进 |
| **KPT** | 保持→问题→尝试 | 周会、日报、敏捷迭代 |
| **ECRS** | 取消→合并→重排→简化 | 流程优化 |

### 三、深度认知（让思考更深刻）

| 方法 | 核心 | 适用场景 |
|------|------|----------|
| **四步思维法** | 拆分→归纳→联系→提炼 | 碎片信息整合、跨领域提炼 |
| **费曼技巧** | 输出倒逼输入，用大白话讲给外行 | 读书笔记、技术消化 |
| **MECE** | 相互独立，完全穷尽 | 所有总结的分类质检工具 |

## 方法选择速查

```
会议记录    → ORID
项目复盘    → GRAI
技术文章    → 四步思维法 + 金字塔原理
流程优化    → ECRS
学习笔记    → 费曼技巧
周报/汇报   → KPT + KISS
决策文档    → 金字塔原理 + MECE
碎片信息    → 四步思维法
```

## 避坑建议

1. **避免"伪总结"**：只罗列"做了什么"而没有"为什么"和"价值"的只是流水账
2. **AI 辅助技巧**：指令用「先用一句话概括核心结论，再按【结论】+【依据】格式展开」
3. **按需选择**：不要贪多，日常汇报用金字塔+KISS；项目结束用GRAI/ORID；流程优化用ECRS
