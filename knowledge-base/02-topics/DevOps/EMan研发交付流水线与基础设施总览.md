# EMan 研发交付流水线与基础设施总览

> **核心结论**：EMan 的研发交付体系由「GitLab 托管源码 → Jenkins 拉码构建打包 → 198 服务器接收产物供产研自动提包」三段代码流水线，加上独立存在的「EMan 菜单平台（197）」维护菜单 / 字段 / 国际化等应用级配置，两条链路共同构成从代码到可运行系统的完整交付支撑。

**提炼方法**：金字塔原理——先给结论，再按「代码流水线」与「应用配置」两大 MECE 维度展开 3 个支撑论点（源码与构建、产物分发、应用配置），每个论点标注 IP/端口、职责与关键说明。

## 基础设施一览表

| 环节 | 系统 | 地址 | 职责 |
|------|------|------|------|
| 源码托管 | GitLab | `192.168.252.140` | 提供代码仓库，供 Jenkins 拉取 |
| CI/CD 构建 | Jenkins | `192.168.252.133:8011` | 拉取代码并执行流水线打包 |
| 产物分发 | 整包构建产物服务器 | `192.168.252.198` | 接收 Jenkins 通过 SSH 推送的构建产物，产研人员在此自动提包 |
| 应用配置 | EMan 菜单平台 | `192.168.252.197` | 维护 EMan 系统的菜单、字段、国际化文件，是系统生效的必经环节 |

---

## 论点一：源码与构建环节（GitLab + Jenkins）

- **GitLab（192.168.252.140）**：作为唯一的代码源，承担版本管理与代码托管职责，是整条链路的起点。
- **Jenkins（192.168.252.133:8011）**：作为 CI/CD 引擎，主动从 GitLab 拉取代码，触发流水线完成编译、打包等构建动作。
- **依赖关系**：Jenkins 对 GitLab 是强依赖——GitLab 不可用则流水线无法启动；两者结合构成"代码→构建"的标准 CI 前段。

## 论点二：产物分发环节（198 整包构建产物服务器）

- Jenkins 流水线打包完成后，通过 **SSH** 将整包构建产物推送到 `192.168.252.198`。
- 产研人员直接在该服务器上**自动提包**，即该服务器承担"构建产物的落地与分发中心"角色，是打包与实际部署/测试之间的中转环节。
- 这一环节决定了 Jenkins 构建结果如何被下游（部署、测试、发布）消费，是流水线的"最后一公里"。

## 论点三：应用配置环节（EMan 菜单平台，独立于代码流水线）

- `192.168.252.197` 上的 EMan 菜单平台，专门维护 EMan 系统的**菜单、字段、国际化文件**。
- 关键约束：**这类配置必须在 EMan 系统中完成**，不能通过代码流水线（GitLab/Jenkins）替代或绕过——即它是与代码构建并行、但独立管理的"应用运行时配置"环节。
- 与前两个环节的区别：前两者解决"代码怎么变成可运行的包"，而 197 解决"系统运行所需的业务配置从哪里来"，二者维度不同、互不重叠（MECE）。

## 整体链路示意

```
GitLab(.140)  --拉取代码-->  Jenkins(.133:8011)  --SSH推送产物-->  整包构建产物服务器(.198)  --自动提包-->  产研人员/部署环境
                                                                                                              ▲
                                                                                          EMan菜单平台(.197) ─┘
                                                                                     （菜单/字段/国际化配置，独立维护，运行时生效）
```

## 待关注点（建议后续补充确认）

| 关注点 | 说明 |
|--------|------|
| 权限与安全 | Jenkins→198 的 SSH 推送账号权限范围、198 上产研自动提包的访问控制是否最小化 |
| 配置一致性 | 197 上的菜单/字段/国际化配置变更，是否有版本记录或与代码版本对应关系，避免"代码升级了但配置没跟上" |
| 单点风险 | 四个系统均为单机地址，未见冗余/高可用说明，需确认是否有备份或监控 |
| 监控告警 | Jenkins 构建失败、198 推送失败、197 配置变更等是否接入统一监控告警 |
